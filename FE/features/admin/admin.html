Cấu Hình Hệ Thống & Trí Tuệ Nhân Tạo AI

Thiết lập thông số mô hình AI, định mức hạn ngạch miễn phí và phát thông báo hệ thống.

Cấu hình Trí tuệ nhân tạo (AI Engine & Gateway)

Chọn cấu hình mẫu hoặc tự điền thông số chi tiết bên dưới.
Tên nhận diện nhà cung cấp dịch vụ LLM.
Giao thức tương thích chuẩn OpenAI Chat Completions được hỗ trợ bởi hầu hết các nhà cung cấp.
Đường dẫn gốc Gateway (yêu cầu HTTPS cho máy chủ từ xa, cho phép HTTP cho localhost/loopback).
Nhập chính xác Model ID theo danh mục nhà cung cấp công bố. Có thể tự do nhập mô hình bất kỳ.
Xác định nguồn khóa API hiệu lực khi máy chủ thực thi tác vụ AI.
Để trống nếu muốn giữ nguyên khóa API hiện tại trên máy chủ. Khóa mới sẽ được mã hóa an toàn bằng ASP.NET Core Data Protection.

Phân biệt cấp độ trạng thái AI:
1. Cấu hình máy chủ: Thông tin endpoint và khóa đã lưu trong database (chưa kiểm chứng kết nối live).
2. Health Check Ping: Kiểm tra bắt tay HTTP và tính hợp lệ của API Key với AI Gateway.
3. Suy luận phỏng vấn: Yêu cầu mô hình đang Active (không bị MODEL_INACTIVE), hỗ trợ System Role và còn đủ hạn mức Tokens.
Giá trị thấp: Chính xác cao; Giá trị cao: Mở rộng tình huống đa dạng (0.1 - 2.0).
Số tokens tối đa AI sinh ra cho mỗi lượt phản hồi (1 - 32000).
Số phiên phỏng vấn miễn phí cho mỗi ứng viên trong một tháng.
