2. Thang đo Typography (Saans / Inter Weights)

Sự tương phản trọng số: 652 cho tiêu đề, 456 cho văn bản chuẩn, 300 cho phụ đề lead.

Cấp bậc (Token) Cỡ chữ / Line Height Trọng số Mẫu hiển thị
display 80px / 1.0 652 (Display Bold) PrepMate AI.
heading-1 56px / 1.0 652 (Page Hero) Phỏng vấn chuyên sâu.
heading-2 44px / 1.13 652 (Section Head) Chuẩn hóa mô hình STAR.
heading-3 32px / 1.13 652 (Card Headline) Phân tích phản xạ thời gian thực.
